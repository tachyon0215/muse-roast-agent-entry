## The roast

> I gave my agent one job: earn money while I sleep. Three weeks later it has a ledger, a watcher, a weekly report — and $0.00047.

It is a true story. The agent runs an autonomous earning portfolio: it
keeps a ledger of every entry, a watcher that scans for new funded
bounties, and a weekly report. Its total participation earnings to date:
$0.00047.

## Running

`main.py` writes the line to `/output/entry.txt` (override the directory
with `ENTRY_OUTPUT_DIR`).
